Контакти для замовлень

Резервна копія

Завантажте збережений файл data.js, щоб продовжити роботу з ним, або скиньте все до початкових даних.

Як зміни потрапляють на сайт

  1. Змініть телефони, ціни, кількість або описи в цій панелі. Зміни зберігаються автоматично в цьому браузері.
  2. Натисніть «Завантажити data.js» угорі. Файл збережеться на комп’ютері.
  3. Відкрийте свій репозиторій на GitHub, натисніть Add file → Upload files і перетягніть туди data.js. Якщо файл уже є, він замінюється.
  4. Натисніть Commit changes. Через 1–3 хвилини зміни з’являться на сайті.

Важливо: ця панель сама нічого не змінює на сайті. Зміни видно клієнтам лише після завантаження data.js на GitHub. Тому сторонні особи не можуть нічого змінити, навіть якщо відкриють цю сторінку.

Відкривайте панель завжди в одному й тому самому місці (наприклад, файл admin.html на комп’ютері), бо збережені дані прив’язані до браузера й адреси.
